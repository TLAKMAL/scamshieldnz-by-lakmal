# ScamShield NZ — by Lakmal Perera

An independent academic web demonstration based on a Power Platform capstone.

## Host on GitHub Pages
1. Sign in to your GitHub account and create a new PUBLIC repository named scamshieldnz-by-lakmal. Add a README when creating it.
2. Extract this ZIP on your computer.
3. In the repository, choose Add file > Upload files. Upload index.html, style.css, app.js, the assets folder, and this README.md into the repository root. Do not upload the ZIP itself or an enclosing folder.
4. Commit the files.
5. Open Settings > Pages. Set Source to Deploy from a branch, select main and /(root), then Save.
6. Wait for the deployment to finish. Copy the published URL shown in Settings > Pages.

No Node installation, build command, server, database or Microsoft account is needed. All links to scripts and assets are relative, so the site works at a repository subpath. The empty .nojekyll file disables Jekyll processing; if your file picker hides it, the ordinary non-underscore assets still work with the default Pages build.

## Files
- index.html — website and project showcase
- style.css — responsive styles
- app.js — eight rule groups, assessment details, session summary and JSON download
- assets/ — screenshots of the original Power Apps and Power BI artefacts

## Important boundaries
The original artefact used Power Apps/Power Fx, Excel on OneDrive and Power BI. This HTML/CSS/JavaScript website is a separate AI-assisted web adaptation, not a Power Apps export. It reproduces the documented rule groups and weights; matching behavior may differ from the original formula. Historical capstone evaluation results do not validate this web adaptation.

Messages are processed in the browser. No application network requests or persistent browser storage are used. Session statistics reset on reload. Result downloads omit message text. The hosting provider may independently process ordinary website access logs.

Guidance only: words and scores do not prove fraud or establish safety. Do not enter personal or sensitive information. This demonstration is not a production security product or an official Microsoft/NZ government service.
